Mental model

An array is just a box of numbers with a shape attached.

Almost every numpy bug is a shape bug, not a logic bug. Once you can read a shape and predict what an operation does to it, the functions themselves stop mattering as much — you just look them up. That's what this page is for: a single place to come back to mid-assignment when you've forgotten a name or a rule.

In machine learning code, rows are usually examples and columns are usually features. Click a row or column index on the right to see what slicing actually returns.

01Creating arrays

Most assignments start by either building a small array by hand, or generating one with a helper function. These five cover almost every case you'll need.

From a Python list

np.array() wraps a list or nested list into an ndarray. Nesting depth becomes dimensionality: a list of numbers becomes 1D, a list of lists becomes 2D.

Pre-filled arrays

These are for when you know the shape before you know the values — common for initializing centroids, accumulators, or placeholders.

Ranges

arange behaves like Python's range (stop is excluded). linspace is different on purpose: you give it a count, not a step, and the endpoint is included.

Random arrays

np.random.seed() fixes the random stream so your output is reproducible — call it once near the top of a cell before any random call you want to be able to repeat.

02Shape & reshaping

Shape is the single most useful thing to check when something goes wrong. Three attributes and a handful of functions cover it.

Reshaping never changes the data, only how it's laid out. The same 12 values can be arranged as a flat row, a 3×4 grid, a 4×3 grid, and so on — try it below.

Transpose and adding axes

.T swaps rows and columns. [:, None] (or np.newaxis) turns a 1D vector into a column; it's the trick behind a lot of broadcasting magic later on.

Quick checkWhenever a result "looks wrong," the first thing to print is .shape — not the values. A shape mismatch is almost always the actual bug.

03Indexing & boolean masks

Slicing works like Python lists. Boolean masking is the part that feels new — and it's exactly what compute_centroids needed.

Boolean masks — the K-means pattern

idx == k doesn't compare the whole array at once — it builds a new array of True/False, one per row, and X[mask] keeps only the rows where it's True. This is exactly how compute_centroids finds "all points assigned to cluster k" without writing a filter loop.

np.where(condition) gives you the indices instead of the filtered values — useful when you need positions, not contents.

04The axis parameter

This is the one that trips up almost everyone at first. axis names the dimension that gets collapsed — not the one that survives.

Below: three students, four quizzes. Rows are students, columns are quizzes. Click a row/column index, or use the buttons to collapse a whole axis at once.

Memory trickaxis=0 walks down the rows, so it collapses rows and leaves one value per column. axis=1 walks across the columns, so it collapses columns and leaves one value per row. If you're not sure, check which dimension disappeared in the output shape — that's the axis you used.

05Broadcasting

Broadcasting is how numpy lets you combine arrays of different shapes without writing a loop to line them up yourself.

The rule, compared from the right-hand side of each shape: two dimensions are compatible if they're equal, or if one of them is 1 (it gets stretched to match). A vector of shape (3,) can be added to every row of a (2, 3) matrix because numpy treats the vector as (1, 3) and stretches it down to 2 rows.

Where it failsIf the trailing dimensions don't match and neither is 1, you'll get ValueError: operands could not be broadcast together. The fix is almost always reshaping one side with [:, None] or [None, :] so the shapes line up on purpose.

06Reductions & the arg-* convention

Reductions turn many numbers into fewer. The naming convention for finding where something happens is consistent enough to guess from.

Naming conventionAny numpy function starting with arg — argmin, argmax, argsort, argwhere — returns an index, not a value. Once you've noticed this once, you can guess the rest without looking them up.

07Linear algebra essentials

Most ML assignments only need a handful of linalg functions. If a problem mentions distance, magnitude, or "norm," this is the first place to look.

np.linalg.norm also takes an axis argument, so you can get the distance from every row of a matrix to a single point in one call — no loop required.

Dot product vs. elementwise multiply

These two look similar and do very different things. * multiplies position-by-position; @ (or np.dot/np.matmul) does real matrix multiplication.

08Vectorization: trading loops for shape tricks

The double for loop in find_closest_centroids is written that way deliberately, to teach the logic clearly. Once the logic clicks, here's the version with no loop at all — same answer, using only what's in sections 04 and 05.

The trick is X[:, None, :] turning X into shape (m, 1, n) and centroids[None, :, :] turning centroids into (1, K, n). Broadcasting stretches them against each other into (m, K, n) — every point compared against every centroid at once — then norm(..., axis=2) collapses the feature dimension, leaving an (m, K) distance table.

You don't need this for the assignmentThe loop version is correct and is what's graded. This is here for when you want to see where the "no loops" style in real ML code comes from.

09Common mistakes

Six things that look like logic bugs but are actually syntax or shape bugs.

1. Wrong axis

Swapping axis=0 and axis=1 still runs without error — it just silently gives you the wrong numbers. Always sanity-check the output shape against what you expected to collapse.

2. Slicing returns a view, not a copy

Modifying a slice modifies the original array too, because slicing shares the same underlying memory.

Use .copy() when you need an independent array.

3. Integer dtype silently truncates

If an array was created with an integer dtype (often via np.zeros(n, dtype=int)), assigning a float into it gets truncated, not rounded — with no warning.

4. Comparing floats with ==

Floating point arithmetic is approximate. Use np.isclose instead of == whenever you're comparing computed floats.

5. Broadcasting error from mismatched trailing dimensions

Covered in section 05 — the fix is almost always an explicit [:, None] reshape on one side.

6. Forgetting that reductions remove a dimension

X.sum(axis=1) on a (m, n) array returns shape (m,), not (m, 1). If you need to broadcast the result back against the original array, you may need keepdims=True to keep that dimension as length 1 instead of dropping it.

11When you're stuck

The actual skill isn't memorizing function names — it's knowing how to find the right one fast.

  1. Restate what you're trying to do in plain English before touching code. "The norm between x(i) and centroid j" is a search query in disguise.
  2. If the problem mentions distance, magnitude, or a matrix operation, check np.linalg first — most linear-algebra-flavored functions live there.
  3. If a function name starts with arg, it returns an index, not a value. You can often guess the right function exists before you've looked it up.
  4. If a reduction "isn't doing what I expect," print the shape of the result. The axis that's missing from the new shape is the one that got collapsed — that tells you immediately if you used the wrong one.
  5. Search "numpy + plain English description" rather than guessing at function names — "numpy index of minimum value," not "numpy minarg."
